Небольшая головоломка, созданная в GDevelop. Игрок проходит несколько уровней, двигает ящики, взаимодействует с объектами и должен добраться до цели.

О проекте
Это учебный игровой проект с несколькими сценами:

Level_1
Level_2
Level_3
Win
В игре используются простые 2D-объекты: персонаж, стены, земля, ящики и цель уровня.

Как открыть проект
Установите GDevelop.
Скачайте или клонируйте этот репозиторий.
Откройте файл Lesson_4.json в GDevelop.
Нажмите Preview, чтобы запустить игру.
Управление
Управление зависит от настроек проекта в GDevelop. Обычно для движения используются клавиши со стрелками или WASD.

Структура проекта
Lesson_4.json — основной файл проекта GDevelop.
assets/ — дополнительные изображения и игровые ресурсы.
*.png, *.jpg — спрайты, элементы интерфейса и изображения для игры.
Lesson_4.json.autosave — автосохранение проекта.
Цель игры
Пройти уровни и добраться до финального экрана победы.

Статус
